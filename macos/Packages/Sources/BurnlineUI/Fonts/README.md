# Fonts

`Silkscreen-Regular.ttf` is Silkscreen by The Silkscreen Project Authors,
from [google/fonts](https://github.com/google/fonts/tree/main/ofl/silkscreen),
kept exactly as published. It is not part of Burnline and is not covered by
its license: it is under the SIL Open Font License 1.1, in `OFL.txt` beside it
and in the About window. The OFL allows bundling it with software under any
license, AGPL included, as long as the font is not sold on its own.

Burnline registers it for its own process at run time and uses it only for
the pixel-art labels on the Streaks card.
