# Animations

`fire.json` is the fire emoji (U+1F525) from Google's
[Animated Noto Emoji](https://googlefonts.github.io/noto-emoji-animation/),
downloaded from `fonts.gstatic.com/s/e/notoemoji/latest/1f525/lottie.json`
and kept exactly as published. It is not part of Burnline and is not covered
by its license: it is © Google LLC under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), credited in
`NOTICE` and the About window, which CC BY allows alongside software under
any license, AGPL included.

Burnline plays it with Lottie on the Streaks card's dial, turning the colours
of its gradients at run time to match each tier (`FireFlame.swift`). The
shapes and motion are Google's.
